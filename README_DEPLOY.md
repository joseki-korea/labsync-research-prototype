# 건국대학교 학술 연구/논문 관리 시스템 배포 및 운영 가이드

본 시스템은 건국대학교 연구실 및 학술 프로젝트 관리팀을 위한 경량형 통합 웹 애플리케이션입니다.

## 1. 시스템 요구사항
- Docker 및 Docker Compose 환경

## 2. 턴키 1회 클릭 실행
```bash
# 컨테이너 빌드 및 실행
docker compose up -d --build
```
실행 완료 후 브라우저에서 `http://localhost:8080` 접속.

## 3. 주요 기능
- **논문 아카이브**: PDF 업로드 및 메타데이터(제목, 저자, DOI, 게재일) 자동 정리, 다조건 검색
- **과제 WBS 마일스톤**: 연구 과제별 마일스톤 진척률(%) 및 D-Day 카운트다운
- **권한 제어**: 관리자(교수) 및 연구원(학생) 분리 뷰
- **체크리스트**: 논문 작성 및 투고 전 필수 요건 20항목 자체 점검
