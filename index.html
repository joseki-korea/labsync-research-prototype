LabSync 연구 관리 시스템 사용법

대학원 연구 과제의 기획부터 3단 계층(프로젝트·트랙·가설) 관리, 실험 판정 근거 기록, Semantic Scholar 논문 조사 및 로컬 AI 인사이트 연계까지 실무 전 과정을 한눈에 안내합니다.

목차 (Contents) 8개 항목
1

시작하기 (로그인 · 회원가입 · 빠른 테스트 계정)

계정 등록 및 사전 구성된 테스트 계정을 통한 원클릭 시연 방법

LabSync는 대학원 연구실 구성원들이 연구 프로젝트와 가설 검증 내역을 안전하게 공유하고 기록할 수 있도록 설계된 플랫폼입니다.

🔑 회원가입 및 로그인
기관 이메일(예: researcher@lab.ac.kr)과 6자 이상의 비밀번호를 입력해 가입합니다. 회원가입 시 입력하는 이름(표시용)은 가설 작성자, 판정 갱신자, 인사이트 작성자로 자동 표기됩니다.
⚡ 원클릭 빠른 테스트 계정
회원가입 없이 즉시 기능을 둘러보고 싶을 때, 로그인 화면 하단의 [원클릭 계정 입력] 버튼을 누르면 이메일과 비밀번호가 자동 입력되어 즉시 로그인할 수 있습니다.
💡
사전 구성된 테스트 계정 정보:
  • 계정 A (NLP Lead): test_user_a@research-lab.ac.kr (비밀번호: Password123!) — 자연어처리 및 지식그래프 추론 연구 담당
  • 계정 B (Bio Lead): test_user_b@research-lab.ac.kr (비밀번호: Password123!) — 단백질 구조 및 신약 후보물질 탐색 연구 담당
2

대시보드 보는 법 (통계 지표 · 최근 가설 · 프로젝트 요약)

연구실 전체 가설의 실시간 검증 현황 파악 및 드릴다운 탐색

로그인 후 처음 마주하는 대시보드는 연구실 내 모든 연구 가설의 상태를 종합 집계하는 중앙 관제탑입니다.

📊 5가지 통계 카드(KPI)의 의미

Total 전체 연구 가설
연구실에 등록된 모든 가설 명제의 총수입니다. 카드를 클릭하면 가설 요약 테이블의 '전체' 보기로 이동합니다.
Testing 검증 진행중
현재 벤치마크 실험 수행, 데이터 측정, 모델 학습이 진행 중인 활성 가설입니다.
Supported 가설 채택
실험 결과와 통계적 유의성이 검증되어 연구팀에서 타당성을 공식 인정한 가설입니다.
Rejected 가설 기각
실험 결과 반례가 발생하거나 유의미한 성능 개선이 없어 기각 처리된 가설입니다.
Inconclusive 판정 유보
실험 데이터가 부족하거나 결과가 모호하여 추가 실험이 요구되는 보류 가설입니다.
⚡ 원클릭 필터 스마트 바로가기
각 통계 카드를 클릭하면 해당 검증 상태의 가설만 즉시 필터링된 요약 테이블로 이동합니다.
🕒 최근 판정 갱신 가설 패널
가장 최근에 상태나 판정 근거(Rationale)가 업데이트된 가설 5건을 실시간 표시합니다. 가설명을 클릭하면 3단 상세 뷰로 이동하여 판정 근거와 연결된 논문을 즉시 열람할 수 있습니다.
📁 내 연구 프로젝트 요약 패널
참여 중인 연구 프로젝트와 소속 트랙 수를 한눈에 파악합니다. + 새 프로젝트 버튼으로 신규 프로젝트를 생성하거나, 프로젝트 카드를 클릭해 워크스페이스로 이동합니다.
3

프로젝트 · 트랙 · 가설 만들기 (3단계 계층 구조)

연구 과제의 체계적인 구조화와 워크스페이스 내 생성 절차

복잡한 대학원 연구를 명확하게 관리하기 위해 LabSync는 3단계 계층 구조(3-Tier Hierarchy)를 채택하고 있습니다.

1️⃣ 프로젝트 (Project)
연구 과제의 최상위 대주제입니다.
예: "멀티모달 지식그래프 추론 모델 개발", "단백질 표적 발굴 AI"
2️⃣ 트랙 (Track)
프로젝트 내 세부 연구 방향 및 분과입니다.
예: "트랙 A: 그래프 임베딩 기법", "트랙 B: 경량화 어텐션 구조"
3️⃣ 가설 (Hypothesis)
실험을 통해 검증할 구체적인 학술 명제입니다.
예: "GNN 깊이를 8로 확장 시 소분자 결합 친화도 예측 오차가 12% 감소할 것이다"

🛠️ 워크스페이스에서 생성하는 단계별 절차

1
프로젝트 진입 또는 신규 생성
상단 메뉴 프로젝트 목록에서 작업할 프로젝트 카드를 클릭하여 워크스페이스를 엽니다. 새 프로젝트가 필요한 경우 + 새 프로젝트 버튼을 누르고 프로젝트 이름과 설명을 작성합니다.
2
연구 트랙 (Track) 추가
워크스페이스 좌측 연구 트랙 패널의 + 트랙 버튼을 클릭합니다. 트랙명(예: "데이터 전처리 파이프라인")과 설명을 입력하여 연구 분과를 추가합니다.
3
연구 가설 (Hypothesis) 등록
우측 가설 목록 패널의 + 가설 등록 버튼을 클릭합니다. 가설 명제(Title), 세부 배경 및 실험 계획(Description), 소속 트랙을 지정하여 생성합니다. 생성된 가설은 초기 초안 (Draft) 상태로 등록됩니다.
4

가설 판정 및 상태 변경 (라이프사이클 & 판정 근거 필수)

검증 단계별 상태 전이 규칙과 판정 근거(Rationale) 의무화의 이유

연구 가설은 실험 진행 상황에 따라 체계적인 라이프사이클을 거치며 상태가 업데이트됩니다.

🔄
가설 상태 라이프사이클 (State Lifecycle):
초안 (Draft) → 실험 착수 → 검증중 (Testing) → 실험 및 통계 검증 후 → 채택 (Supported) / 기각 (Rejected) / 유보 (Inconclusive)
💡
판정 근거 (Rationale) 작성이 필수인 이유

학술 연구에서는 단순한 '채택/기각' 버튼 클릭보다 "어떤 정량적 실험 수치(Accuracy, F1-score, p-value, RMSE 등), 데이터셋 조건, 대조군 비교, 또는 관측된 반례에 의해 결론이 내려졌는가"가 연구실의 핵심 자산입니다.
판정 근거 작성을 필수로 제한함으로써 연구의 재현성(Reproducibility)을 보장하고, 연구 노트 작성 및 논문 초안 작성 시 결과(Results) 섹션의 근거 자료로 즉시 활용할 수 있습니다.

⚙️ 상태 변경 방법
가설 카드 또는 가설 상세 페이지에서 [판정 / 상태 변경] 버튼을 누릅니다. 변경할 상태를 선택하고, 실험 측정 수치와 판정 근거를 텍스트 박스에 상세히 작성한 후 [판정 저장]을 클릭합니다.
5

가설 요약 테이블 (필터 · 정렬 · 실시간 검색)

전체 프로젝트 가설 통합 조회와 강력한 다중 필터링 활용법

상단 네비게이션의 가설 요약 테이블은 여러 프로젝트와 트랙에 흩어져 있는 수십 개의 가설을 하나의 스프레드시트 형태로 집계하여 빠르게 탐색할 수 있는 뷰입니다.

🔍 실시간 통합 검색
검색창에 가설 명제, 프로젝트명, 트랙명뿐만 아니라 연구원이 작성한 판정 근거(💡 Rationale) 본문 키워드까지 실시간으로 매칭되어 원하는 가설을 즉시 찾아냅니다.
🏷️ 상태별 탭 필터링
전체, 초안, 검증중, 채택, 기각, 유보 상태 알약 버튼을 원클릭하여 특정 검증 단계에 위치한 가설들만 모아볼 수 있습니다.
📁 프로젝트 선택 필터
우측 상단 프로젝트 드롭다운 메뉴에서 특정 연구 과제를 선택하여 해당 과제에 소속된 가설들만 집중 조회할 수 있습니다.
↕️ 다각도 정렬 및 드릴다운
최근 판정 갱신일(최신순/오래된순), 가설명(가나다순), 검증 상태순으로 테이블을 정렬할 수 있으며, 가설명을 클릭하면 3단 상세 페이지로 즉시 진입합니다.
6

논문 조사 파이프라인 (Semantic Scholar 검색 · 적합도 점수 · 인사이트)

실시간 학술 DB 검색, 가설 연계 적합도(Fit Score) 산출, 연구 보관함 관리

논문 조사 뷰는 전 세계 최대 오픈 학술 데이터베이스인 Semantic Scholar와 실시간 연동되어 선행 연구를 탐색하고 연구 가설과 매칭하는 파이프라인을 제공합니다.

🔎 1. Semantic Scholar 실시간 검색
검색창에 영문/한글 키워드, 논문명, 저자명을 입력하거나 추천 키워드 태그(Graph Neural Networks, Attention Mechanism 등)를 클릭합니다. 논문 제목, 저자, 발표연도, 인용수, 초록(Abstract), DOI 원문 링크가 실시간 로드됩니다.
💾 2. 가설 매칭 논문 저장
검색 결과 카드 하단에서 논문을 수집할 소속 프로젝트와 연결 가설을 선택한 후 [💾 이 가설에 논문 저장] 버튼을 누르면 연구실 보관함에 영구 저장됩니다.
🎯
가설 적합도 점수 (Fit Score)의 원리와 의미

선택한 가설의 명제·설명과 논문의 초록·제목 간의 학술 전문 키워드 일치율(Coverage, 75% 가중치) 및 자카드 유사도(Jaccard Similarity, 25% 가중치)를 알고리즘으로 자동 분석하여 15~98점 점수로 환산합니다.

🎯 가설 적합도 70점 이상 (High) : 가설 주제 및 방법론과 직접 일치하는 핵심 선행 논문
🎯 가설 적합도 45~69점 (Mid) : 기반 도메인이나 선행 기법을 다루는 참고 논문
📑 3. 저장된 논문 보관함 & 인사이트 메모
저장된 논문 보관함 탭에서는 프로젝트별/가설별로 수집된 논문들을 한눈에 모아보고, 연구원이 직접 읽고 분석한 요약 및 실험 아이디어를 인사이트 메모 (Insight Summary)에 기록하여 동료들과 공유할 수 있습니다.

로컬 AI 연구 인사이트 (보안 이유 · 로컬 서버 실행 · 활용법)

연구 가설과 논문 초록을 로컬 환경에서 안전하게 교차 분석하는 방법

🔒
왜 별도의 로컬 AI 서버가 필요한가요? (보안상 이유)

대학원 연구실의 미발표 연구 가설과 핵심 아이디어가 외부 클라우드나 상용 AI 서버로 유출되는 것을 원천 차단하기 위해, 연구원 PC 로컬 환경(127.0.0.1:8787)에서만 실행되는 독립 AI 파이프라인을 사용합니다.

💻 로컬 AI 서버 구동 방법 (local-ai-server 폴더 안내)

터미널을 열고 프로젝트 내 local-ai-server 디렉토리로 이동한 뒤 아래 명령어를 실행합니다 (Node.js 18 이상 및 Claude CLI 환경 필요).

cd local-ai-server && npm install && node server.js

✓ 실행 후 터미널에 ResearchLab Local AI Server running on http://127.0.0.1:8787 문구가 표시되면 정상 실행된 상태입니다.

✨ AI 인사이트 버튼 사용법

1
가설에 연결된 저장 논문 확인
상단 메뉴 논문 조사 → 저장된 논문 보관함 탭으로 이동합니다.
2
AI 인사이트 생성 클릭
논문 카드 우측의 ✨ AI 인사이트 생성 (로컬 Claude) 버튼을 클릭합니다. 로컬 AI가 논문 초록과 가설 명제를 정밀 대조하여 가설 검증 포인트 및 연구 시사점을 분석합니다.
3
인사이트 검토 및 메모 저장
텍스트 영역에 자동 생성된 분석 내용을 검토·수정한 뒤 [메모 저장] 버튼을 누르면 연구실 데이터베이스에 영구 보관됩니다.

자주 묻는 질문 (FAQ)

연구원들이 자주 마주치는 의문점과 해결 가이드

Q1 저장된 논문에서 [AI 인사이트 생성] 버튼을 눌렀는데 오류 메시지가 나오거나 동작하지 않아요.
A
다음 두 가지 사항을 확인해 주세요:
1. 연결 가설 존재 여부: 해당 논문이 특정 연구 가설에 연결되어 있는지 확인하세요. 연결된 가설이 없으면 비교 분석할 기준 명제가 없어 생성이 제한됩니다.
2. 로컬 AI 서버 실행 여부: PC 터미널에서 cd local-ai-server && node server.js 명령어로 서버(포트 8787)가 실행 중인지 확인하세요. 로컬 서버가 꺼져 있으면 연결 오류가 발생합니다.
Q2 가설 적합도 점수(Fit Score)는 어떻게 산출되며 점수를 높이려면 어떻게 해야 하나요?
A
논문 초록/제목의 학술 전문 단어들과 연구 가설의 제목/설명 간의 키워드 매칭률(75%) 및 자카드 텍스트 유사도(25%)를 바탕으로 계산됩니다. 가설을 등록할 때 연구 방법론, 타겟 분자명, 모델 아키텍처 등 구체적인 전문 용어를 상세히 작성할수록 더욱 정확하고 높은 적합도 점수가 도출됩니다.
Q3 가설 상태를 변경할 때 판정 근거(Rationale)를 빈칸으로 둘 수 없나요?
A
빈칸으로 둘 수 없습니다. 대학원 연구의 신뢰성과 재현성을 보장하기 위해, '왜 이 가설이 채택/기각/유보되었는지'에 대한 정량적 수치(정확도, F1-score, p-value 등)나 실험 반례를 필수로 남기도록 시스템적으로 의무화되어 있습니다.
Q4 Semantic Scholar 검색 결과가 빈 화면으로 나오거나 지연될 때는 어떻게 하나요?
A
Semantic Scholar 해외 학술 API의 네트워크 상황에 따라 일시적으로 응답이 지연될 수 있습니다. 너무 긴 자연어 문장보다는 핵심 영문 키워드(예: Graph Neural Networks, Transformer Attention)로 검색하시거나, 검색창 하단의 '추천 키워드 태그'를 클릭해 시연해 보세요.
